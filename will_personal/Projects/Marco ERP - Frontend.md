# Marco ERP - Frontend

Frontend repo for [[Marco ERP]]. React + Vite SPA, TanStack Query, i18next.

## Repo
- Local path: `~/repos/marco-frontend`
- Remote: `git@github.com-wmartinez79:wmartinez79/marco-frontend.git`
- Framework: React + Vite, TypeScript, Node.js v22
- State: TanStack Query for server state
- Forms: React Hook Form + Zod
